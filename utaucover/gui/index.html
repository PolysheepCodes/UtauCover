GAME isn't installed. UtauCover charts notes with the GAME transcriber built into UtauV, which is far more accurate. Without it, builds fall back to the built-in engine. Download GAME's .oudep package and drag it onto UtauV's window (or run its "transcribe audio to notes" tool once, which offers to download it), then check again.
